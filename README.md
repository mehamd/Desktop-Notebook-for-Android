# Desktop Notebook for Android
مفكرة متطورة ومميزة للأندرويد مصممة خصيصاً لتمنحك تجربة تشبه نظام ويندوز تماماً. تتميز بتصميم أنيق يدعم تخصيص الخلفيات، وقائمة سياق (Context Menu) احترافية تمنحك تحكمًا كاملاً، مع دعم التبويبات المتعددة، والبحث والاستبدال، والنسخ واللصق، واختصارات لوحة المفاتيح لتجربة كتابة يومية سريعة ومريحة.

A sophisticated and unique notepad for Android designed to give you a true Windows-like experience. It features an elegant design supporting background customization, a professional Context Menu for full control, multi-tab support, search & replace, copy/paste, and keyboard shortcuts for a seamless daily writing experience.

## 🖥️ Desktop Mode & Samsung DeX Support / دعم وضع سطح المكتب و DeX
تم تصميم المفكرة وتطويرها بعناية لتعمل بسلاسة كاملة على بيئات سطح المكتب للأندرويد:
- **Samsung DeX:** دعم كامل للتكبير والتصغير، والنوافذ المنبثقة، وقائمة السياق بلمسة واحدة.
- **Android Desktop Mode / PrimeOS / Bliss OS:** متوافقة مع أنظمة سطح المكتب المتعددة للعمل بالماوس ولوحة المفاتيح بمرونة.
- **Keyboard Shortcuts:** دعم الاختصارات الشهيرة مثل (`Ctrl+C`, `Ctrl+V`, `Ctrl+Z`, `Ctrl+F`).

Designed and optimized for Android Desktop environments:
- Fully compatible with **Samsung DeX** freeform windowing and right-click context menus.
- Enhanced layout for mouse and keyboard productivity on Android Desktop interfaces.
